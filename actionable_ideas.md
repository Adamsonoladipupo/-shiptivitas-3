# Shiptivity — Three Actionable Ideas to Increase DAU

## Context

The Kanban Board was released on **June 2, 2018**.

Observed average daily active users (DAU) increased from **3.63 before the release** to **11.79 after the release**. This is an observed association and does not, by itself, prove that the Kanban Board alone caused the increase.

---

## 1. Smart Task Reminders

### Hypothesis

If Shiptivity reminds users when cards require attention, users will have additional reasons to return to the application.

### Expected Impact

Increase repeat visits and DAU by prompting users to act on overdue, stalled, or upcoming tasks.

### What the feature is

A notification system that monitors cards and sends reminders when a card needs attention—for example, when a task is overdue, approaching its due date, or has remained in the same status for an unusually long period.

---

## 2. My Day Dashboard

### Hypothesis

If users have a personalized view of the work requiring their attention today, Shiptivity can create a stronger daily-use habit.

### Expected Impact

Increase daily return visits by giving users a clear reason to open Shiptivity each day and helping them quickly identify their highest-priority work.

### What the feature is

A personalized daily dashboard showing overdue cards, tasks due today, cards currently in progress, and priority work. The dashboard provides a single starting point for the user's daily workflow.

---

## 3. Activity Feed

### Hypothesis

If users can easily see recent changes to cards they care about, they will have more reasons to return to Shiptivity and respond to ongoing work.

### Expected Impact

Increase recurring engagement by making workflow activity visible without requiring users to inspect individual cards.

### What the feature is

A centralized activity feed showing recent card movements, status changes, and updates from teammates. Users can select an update to open the relevant card.

---

## Data Rationale

The product ideas build on the observed workflow behavior in the dataset.

There were **200 cards** with status-change activity:

| Status Changes | Number of Cards |
| -------------: | --------------: |
|              1 |              38 |
|              2 |              53 |
|              3 |             100 |
|              4 |               4 |
|              5 |               4 |
|              6 |               1 |

Therefore, **95.5% of cards had between 1 and 3 status changes**.

The proposed features are **hypotheses to test**, rather than guaranteed drivers of DAU.
